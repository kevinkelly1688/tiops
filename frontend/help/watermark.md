# 水印设置

> 💡 管理员定义「页面水印」：登录后在每个页面上铺满一层半透明文字（默认「显示名 登录名 日期」），截屏 / 拍照外泄后可以据此追溯是谁在看。**只有「修改平台设置」权限（settings.edit，即内置管理员）能看到菜单并修改**；所有登录用户都会被动看到水印。默认关闭；设置全局共用，不分集群。它只是前端震慑手段，**不是安全边界**，见文末「已知限制」。

## 这个页面做什么

- 在 [水印设置](go:watermark) 页（侧栏「平台配置」分组）里管理一份**全局**的水印设置：是否启用、文字模板、透明度、字号、旋转角度、颜色、水平 / 垂直间距。
- 页面右侧有**实时预览**：你改任何一项，预览立即重画（预览里的透明度会被放大到至少 0.3，并居中显示，方便看清，**实际水印的透明度以你设置的值为准**）。
- 保存后，**你当前打开的页面立即生效**；其他正在使用平台的人，最迟约 60 秒内自动生效，或刷新页面后立即生效。
- 水印覆盖层不挡任何点击和输入（鼠标事件会穿过它）；登录页上没有水印。

先认识两个词：

- **水印文字模板**：一段文字，里面可以夹带 `{user}` 之类的**变量**，每个看页面的人看到的是用自己的信息替换后的文字。
- **覆盖层**：平台在页面最上面叠的一层透明画布，水印文字就画在这一层上。

## 前置条件

- 运维模式（后端以数据目录启动，需登录）。
- 你是内置「管理员」角色，即具备 settings.edit（这项能力只授予内置管理员，见 [角色权限](help:roles)）。**其他角色在侧栏看不到「水印设置」**，直接打开 `#watermark` 地址会显示「没有权限：修改水印需要「修改平台设置」（settings.edit）能力，只有内置管理员具备。」
- **不需要**打开写操作开关，**不走审批、不需要双人确认**，不产生变更单：水印是平台自己的显示设置，不是对集群的变更。

## 怎么用（按步骤）

### 开启并保存水印

1. 在左侧菜单「平台配置」里点「水印设置」。
   - 你会看到：标题「水印设置 登录后全站叠加 · 对所有用户生效」，上方一条蓝色说明（含一行「最近修改：<用户名> · <时间>」，从没配置过则是「尚未配置过（当前为默认值，水印关闭）」）；左边是表单，右边是「实时预览」。
   - 看不到菜单、或打开后提示「没有权限」：你不是内置管理员，找管理员。
2. 勾选「启用水印」。
3. 在「水印文字（≤ 100 字）」里填模板，例如 `内部资料 {display} {date} {time}`；变量见下一节。
   - 你会看到：右侧预览立刻显示替换后的文字（示例数据用你当前的账号）。文字为空时预览显示「（文字为空）」。
4. 按需调整「透明度」「字号（px，10–48）」「旋转角度」「颜色」「水平间距」「垂直间距」，一边调一边看预览。
5. 点「保存并应用」。
   - 你会看到：提示「水印设置已保存」，蓝色说明里的「最近修改」变成你和当前时间；当前页面立刻出现水印。
   - 与预期不符：表单下方出现红色提示框 → 对照下面「出错提示」。
6. （可选）换另一个账号登录或让同事刷新页面，确认水印里是他自己的名字。

> ⚠️ 保存后**所有用户**（包括生产环境的值班同事）的所有页面都会叠上水印。透明度太高、字号太大会影响阅读，建议先在预览里确认，保存后若觉得太显眼，调低透明度或取消「启用水印」再保存即可，随时可以改回。

### 三个辅助按钮

| 按钮 | 作用 | 要注意 |
|---|---|---|
| 保存并应用 | 校验后写到后端，并立即应用 | 唯一会真正保存的按钮 |
| 恢复默认值 | **只把默认值填进表单**（关闭、`{display} {user} {date}`、0.12、16、-20、`#808080`、120 / 100），不保存 | 填完还要点「保存并应用」才生效；想要的是「关闭水印」就取消勾选「启用水印」后保存 |
| 放弃修改 | 表单回到**当前已保存的值**，丢弃没保存的改动 | 不影响已生效的水印 |

有未保存的改动时直接刷新或关闭浏览器标签，浏览器会弹出「离开页面」确认。

### 关闭水印

1. 打开「水印设置」，取消勾选「启用水印」。
2. 点「保存并应用」。
   - 你会看到：提示「水印设置已保存」，当前页面的水印消失；其他用户最迟约 60 秒内或刷新后消失。文字等其他设置仍保留，下次启用时沿用。

## 区域与参数说明

### 字段

| 字段 | 含义 | 可选值 / 默认 | 后端校验不通过时 |
|---|---|---|---|
| 启用水印 | 是否显示水印 | 勾选 / 不勾；**默认不勾（关闭）** | — |
| 水印文字 | 模板，可含变量 | ≤ 100 个字，不能含换行 / 控制字符；保存时会去掉首尾空白；**默认 `{display} {user} {date}`**；关闭状态下允许为空，启用时不能为空 | 见下方「出错提示」 |
| 透明度 | 水印的不透明程度，越大越明显 | 0.02–0.5；**默认 0.12** | 「透明度须在 0.02–0.5 之间」 |
| 字号 | 文字大小（像素） | 10–48 的整数；**默认 16** | 「字号须在 10–48 之间」 |
| 旋转角度 | 文字倾斜角度，负数为逆时针 | -90–90 的整数；**默认 -20** | 「旋转角度须在 -90–90 之间」 |
| 颜色 | 文字颜色 | `#rrggbb`（颜色选择器）；保存时转小写；**默认 `#808080`（灰）** | 「颜色须为 #rrggbb 格式」 |
| 水平间距 | 相邻两段文字的水平空隙（像素） | 40–400；**默认 120** | 「水平 / 垂直间距须在 40–400 之间」 |
| 垂直间距 | 相邻两行文字的垂直空隙（像素） | 40–400；**默认 100** | 同上 |

> 💡 透明度、字号、间距怎么选：背景是浅色界面时，灰色 + 0.12 左右的透明度既能在截屏里辨认、又不影响阅读；间距越小水印越密、越难被裁掉，但页面越「花」。以你的实际显示器与截屏效果为准。

### 可用变量

| 变量 | 替换成 | 示例 |
|---|---|---|
| `{user}` | 登录名 | `zhangsan` |
| `{display}` | 显示名（没有显示名时用登录名） | `张三` |
| `{env}` | 当前环境：生产 / 预发 / 测试 | `生产` |
| `{date}` | 当天日期 `YYYY-MM-DD`（按浏览器所在时区） | `2026-10-08` |
| `{time}` | 当前时间 `HH:MM`，**精确到分钟**，模板里有它时每分钟自动更新一次 | `14:05` |

- 变量必须**整个写对**（花括号、小写）。除上表五个外，任何 `{…}` 写法都会被保存时拒绝，不会被当作普通文字。想显示花括号本身，目前不支持。
- 每个人看到的是用**他自己的**账号替换后的结果；`{date}` 在跨天后最迟约 60 秒内随自动刷新更新（模板里有 `{time}` 时每分钟更新）。
- **没有** IP 地址变量（平台没有提供）。想让截屏里能追溯到具体的人，用 `{user}` / `{display}` 加 `{date} {time}` 即可。

### 例子

| 模板 | 效果（张三在生产环境） |
|---|---|
| `{display} {user} {date}`（默认） | `张三 zhangsan 2026-10-08` |
| `内部资料 {display} {date} {time}` | `内部资料 张三 2026-10-08 14:05` |
| `{env} · {user}` | `生产 · zhangsan` |

## 出错提示

点「保存并应用」被拒绝时，错误显示在表单下方的红色框里，**表单内容不会丢**，改正后重新保存即可。

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 水印文字最多 100 个字 | 超长 | 精简（输入框本身也限制 100 字） |
| 水印文字不能含换行或控制字符 | 粘贴进了换行 / 不可见字符 | 清掉后重填 |
| 不支持的变量 {x}，可用：{user} {display} {env} {date} {time} | 写了表外的变量，或拼错（如 `{User}`、`{name}`） | 改成可用变量，或删掉花括号 |
| 启用水印时文字不能为空 | 勾了「启用水印」但文字是空 | 填文字，或取消勾选 |
| 透明度须在 0.02–0.5 之间 | 超范围 | 调回范围内 |
| 字号须在 10–48 之间 | 超范围 | 同上 |
| 旋转角度须在 -90–90 之间 | 超范围 | 同上 |
| 颜色须为 #rrggbb 格式 | 颜色值不合规 | 用颜色选择器重选 |
| 水平 / 垂直间距须在 40–400 之间 | 两个间距里至少一个超范围 | 同上 |
| 保存失败：请检查数据目录的权限与磁盘空间 | 平台把设置写盘失败，**没有保存成功，水印仍是旧设置** | 请部署人员检查平台数据目录的权限与磁盘空间，再重试 |
| 没有权限：settings.edit | 你不是内置管理员，或会话已变化 | 找管理员 |
| CSRF 校验失败 | 登录会话已过期或页面太久没刷新 | 刷新页面（必要时重新登录）后再保存 |
| 读取水印设置失败（页面上带「重试」按钮） | 首次加载读取失败 | 点「重试」；仍失败联系部署人员 |

> 💡 字号、角度、间距填了小数时，前端会先四舍五入成整数再提交；上面的范围以后端校验为准。

## 审计与存储

- **审计**：每次保存都写一条审计 `watermark.update`，风险「中」，目标 `watermark`。摘要列出变了哪些项，例如「修改水印设置：启用 false→true；文字「{display} {user} {date}」→「内部资料 {display} {date}」」；没有变化时写「无变化」。保存写盘失败也会记一条，结果为「失败」。到 [权限与审计](help:security) 的「审计日志」按动作检索。
- **存储**：设置保存在平台数据目录下的 `watermark.json`，**全局一份**，不分集群（切换顶栏集群看到的是同一份水印）。文件不存在时按默认值（关闭）；文件损坏或内容不合规时也按默认值处理，下一次保存会覆盖它。
- **谁能读**：任何登录用户都能读取当前设置（浏览器据此画水印）；只有 settings.edit 能修改。
- **接口**：`GET /api/watermark`、`POST /api/watermark`，属于全局端点，由主集群实例处理。

## 原型模式（静态原型，无后端）

在没有后端的静态原型里，「水印设置」页也可以体验：同样的表单与实时预览，示例用户名为「演示用户」；**设置只保存在你自己的浏览器里**，不会写到服务器，也不影响其他人，清除浏览器数据后恢复默认。真实的保存、权限、审计行为只有运维模式才有。

## 已知限制与易混淆点

> ⚠️ **水印不是安全边界**。它只是前端震慑：有开发者工具的人可以隐藏、删除覆盖层或改样式，或者直接保存页面数据。平台会在覆盖层被删除 / 被改样式时自动恢复，但这挡不住有心人。需要强约束（防截屏、防拍照）请在终端、网络或制度层面另行处理，不要把水印当成唯一手段。

- **截屏和打印会带水印**（它画在页面最上层）；**页面之外的导出**（例如下载的文件）里没有水印。
- **生效有延迟**：保存的人立即生效；其他用户最迟约 60 秒内自动生效，刷新页面则立即生效。关闭水印同理。
- **全局设置、不分集群**：所有集群、所有用户共用一份；不能给某个集群或某个角色单独设置。
- **{time} 精确到分钟**；没有秒，也没有 IP 变量。模板里不含 `{time}` 时，水印文字不会每分钟变化。
- **没有登录时没有水印**：登录页不显示水印；退出登录后水印消失。
- **没有在真实多用户、多浏览器环境下大范围验证**：不同浏览器对画布渲染、高分屏缩放的细节可能略有差异，以你实际的截屏效果为准。
- 「最近修改」只显示最后一次保存的人与时间；两位管理员同时修改时，后保存的覆盖先保存的，详细变化靠审计日志追溯。
